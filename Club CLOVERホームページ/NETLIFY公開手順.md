# Club CLOVER 公開手順

この完成版は、管理画面の保存内容をネット上で共有するために Netlify Functions を使います。

## 公開方法

1. このフォルダ一式を GitHub にアップロードします。
2. Netlify にログインします。
3. `Add new site` から GitHub リポジトリを選びます。
4. Build command は空欄でOKです。
5. Publish directory は `.` を指定します。
6. Deploy します。

## 公開後のページ

- ホームページ: `https://あなたのサイトURL/`
- 管理ログイン: `https://あなたのサイトURL/login.html`

## 管理画面ログイン

初期パスワード:

```text
clover2026
```

## できること

- NEWS投稿
- 店舗情報編集
- 料金編集
- SNSリンク編集
- キャスト登録・編集
- 出勤入力
- プロフィール編集

管理画面で保存した内容は Netlify 側に保存され、ホームページを見ている全員に反映されます。

## 注意

画像をたくさん大きいサイズで投稿すると保存データが重くなります。NEWS画像やキャスト写真は、スマホで撮った写真をそのまま使うより、少し軽くした画像を使うのがおすすめです。
